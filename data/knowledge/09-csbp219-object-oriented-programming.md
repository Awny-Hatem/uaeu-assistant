# CSBP219 Object Oriented Programming

CSBP219 is a 3-credit undergraduate course. Its prerequisite is CSBP119 Algorithms and Problem Solving with a minimum grade of D.

The course develops object-oriented programming using classes, objects, inheritance, polymorphism and collection classes. This is the catalog record inspected on 29 September 2026, not a guarantee of term availability or personal registration eligibility.
