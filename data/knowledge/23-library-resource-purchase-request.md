# Library Resource Purchase Request

UAEU Libraries offer a Resource Purchase Request for a new resource that is not available in the library collection.

## Check these routes first

Before submitting a purchase request, first check whether the title is available in the UAEU Library collection and then check **LIWA**.

- If LIWA has the title as a printed book, use **Request Item through Tipasa** to borrow it from a LIWA library.
- If it is an e-book, use the **Resource Sharing** form and specify the chapters requested.
- If no suitable title or alternative is available, submit the purchase request with reasons and comments supporting the request.

The form is **not for purchasing textbooks**. UAEU says it prioritizes resources that support teaching, learning, and research; requests are reviewed and evaluated before approval.

## طلب شراء مورد للمكتبة

خدمة طلب شراء الموارد مخصصة لمورد غير متوفر في مقتنيات مكتبة جامعة الإمارات. افحص مقتنيات المكتبة أولاً ثم **LIWA**. إذا كان الكتاب المطبوع متوفراً في LIWA، استخدم **Tipasa** لطلب استعارته؛ وإذا كان كتاباً إلكترونياً، استخدم نموذج **Resource Sharing** وحدد الفصول المطلوبة. النموذج **ليس لشراء الكتب الدراسية**.
