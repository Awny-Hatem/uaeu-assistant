# Electronic library resources for alumni

The UAEU Main Library page states that the library provides alumni with access to electronic academic resources using their university account.

This statement establishes alumni access to electronic academic resources through a university account. It does not identify every included database, confirm access to a particular publisher resource, or describe account-recovery steps.

## المصادر الإلكترونية للخريجين

تذكر صفحة المكتبة الرئيسية بجامعة الإمارات أن الخريجين يمكنهم الوصول إلى المصادر الأكاديمية الإلكترونية باستخدام حسابهم الجامعي. لا تحدد الصفحة جميع قواعد البيانات المشمولة أو تضمن الوصول إلى مورد ناشر معين.
