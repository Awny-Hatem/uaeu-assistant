    •                                       Subject: This book is about Sniffers and AntiSniffers in a TCP/IP networks.
         Sniffers are programs used by hackers to capture all packets in a network,
         so that hackers can spy any users. The detection of such malicious
         programs is a very hard task. However, AntiSniffers are programs that try to
         detect all hosts running Sniffers in a network. This book will be divided in
         three main parts. The first part describes how Sniffers are implemented. The
         second part presents the dangers of Sniffers and describes many attack
         scenarios that can be performed by Sniffers. The last parts will describe all
         the techniques used to detect a sniffing host in a TCP/IP network. So far,
         there is no book available about Sniffers and AntiSniffers.
