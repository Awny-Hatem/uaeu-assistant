Statistical Consulting Unit
                                                Workshops/Training courses
                                                           Spring 2024
                                                          Workshop #1

Title: Data Visualization with Tableau
Statistical Software: Tableau Desktop
Requirements: Hardware: A laptop capable of running the latest version of Tableau Desktop Knowledge:
Basic data literacy
Instructor: Dr. Kursad Asdemir
Target Group: Anyone interested in gaining insights from data
Date: March 4 – March 10
Period: (12 Hours), 3 days, 4 hours/day
Platform: Face-to-face Meeting
Inclusive of Scientific Materials: PowerPoint Slide Presentation and E-Certificate.
Description:
Public and private organizations have huge amounts of data. There is a great need for individuals who can
make sense of this data.  Tableau Desktop is a powerful data visualization platform which can produce
meaningful information from very large datasets.  It is intuitive, easy-to-use, and produces appealing
visualizations.  The ability to use Tableau Desktop is a vital skill of future managers and analysts who want
success in using data to improve performance and a valuable skill to include in your CV as a job seeker.
Topics Covered:
Day 1:
         User Interface
         Connecting to data
         Data prep
         Basic Charts
Day 2:
         Intermediate Charts
         Calculated Fields
         Table Calculations
