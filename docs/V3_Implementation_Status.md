## Current implementation

- The V3 answer path uses resolution states, source evidence, applicability checks, and deterministic academic models. Route checks verify legacy selector bypass for covered cases, deadline-topic separation, source citations, fail-safe handling, and contextual prerequisite assessment when a student mentions the target, completed, and current courses across turns.
- Course prerequisite follow-ups now resolve explicit course codes with spaces or hyphens, carry forward a clearly established prerequisite intent for short follow-ups, and distinguish the nearest course from the first course mentioned. Deterministic catalog facts are answered before the generic missing-context gate, while personal eligibility requests remain on the assessment path. When an OR prerequisite is already satisfied, the explanation shows the satisfied route and omits irrelevant unmet alternatives.
- Course-history parsing preserves an explicit “passed” result when a student omits the letter grade. Completion-only prerequisites can use it; a minimum-grade rule remains undetermined without the actual grade. It also recognizes coordinated enrollment phrasing such as “I passed X, and am taking Y,” so current courses are not incorrectly treated as missing.
- All 55 degrees in the current official undergraduate catalog have structured current curriculum evidence. This does not mean all historical cohorts, changed degree versions, personal audits, or course offerings are fully modeled.
- The current 2,795-record course snapshot has explicit credit values for its records. GEOL654 is recorded as 3 credits from its official course page; ENVE850 remains a 0-credit candidacy exam. ENVE850's description is not present in the catalog section, so it is not invented. BIOL210 and SWK200 are governed supplemental records from the [official Biology](https://webapps.uaeu.ac.ae/catalog/auto/department_SC_SC_BIOL.asp) and [Social Work](https://webapps.uaeu.ac.ae/catalog/auto/department_HS_HS_SOCW.asp) department catalogs. ELEC490 is now included from the official Electrical Engineering model plan. The importer merges and validates these supplements after every central-index import.
- BIOL210 and ELEC490 have documented credit conflicts across official UAEU sources. Their catalog answers disclose the conflict, cite both sides, and return `CONFLICTED` rather than presenting one credit value as settled. ISEC421 remains the course identity/detail gap: current sources disagree on credits and its old direct course-detail URL no longer resolves to an ISEC421 record. No value is inferred to make the catalog appear complete.
- The deterministic prerequisite parser recognizes explicit `Pre/Co` labels in catalog pre/corequisite alternatives and inline prerequisite expressions. For each official list item, the importer makes adjacent course codes an explicit AND only when the intervening text is empty or an explicit minimum-grade phrase and there is no `and`, `or`, or `Pre/Co` marker; explicit alternatives remain intact. Six exact catalog fragments with malformed or omitted structural operators were checked against their published pages and given source-specific repairs without changing displayed source text. AERO490 now preserves the PHYS200-or-MATH210 alternative and separately requires AERO485 completed or concurrently enrolled. Numeric marks are now supported as explicit prerequisite thresholds; the expanded snapshot structures 1,477 of 1,480 relation records (99.8%). CSBP340 and BMSC711 remain unsupported due dangling `or` operators, and SWK200's English placement-test alternative remains unparsed rather than being treated as a course rule.
- An audit found a separate unsafe manual CSBP340 rule that had converted its dangling catalog `or` into a confident OR alternative. That approved rule is removed; the English/Arabic stored answer and evaluation expectations now state the source ambiguity. CSBP340 personal eligibility requests remain unsupported until UAEU clarifies the catalog requirement.
- The catalog answer renderer now checks prerequisite structure before presenting it. For unsupported source relations it labels the field unresolved and does not present the raw text as a verified prerequisite rule; personal eligibility remains unavailable until a complete source rule exists.
- Recently added program records cover Arabic Language and Literature, Visual Studies and Creative Industries, Geography, Applied Sociology and Social Data Analytics, and Doctor of Medicine. Each record carries explicit source caveats and applicability limits where the official pages conflict or leave gaps.
- Dark-mode controls and styles are absent from the current `app`, `components`, and `lib` source search. A live visual accessibility audit remains outstanding.

### Phase 2 grade-aware preliminary degree audit (2026-11-12)

Fixed a false-completion path in preliminary course comparisons. Previously any parsed grade except literal `F` counted as complete, including numeric marks below the general undergraduate passing threshold. The audit now interprets recognized letter/numeric outcomes only when the selected program is outside the College of Medicine and Health Sciences, which is explicitly excluded from UAEU's published [Grades and Grading procedures](https://www.uaeu.ac.ae/en/about/procedures/admissions_and_enrollment/pro-ae_04_en.pdf). For covered programs, numeric marks below 60 and `F`/`FA`/`NP` remain incomplete and require repetition; `W`/`AW`/`I`/`CC` remain unconfirmed; recognized passing grades count as complete. For Medicine and Health Sciences, marks outside an explicit user-reported pass are left `NEEDS_CONFIRMATION`; the excluded policy is not generalized to those students. The parser now preserves these non-final marks instead of silently dropping them.

The rendered audit now labels below-threshold courses as **repeat required**, separate from courses that are simply remaining or need confirmation, so the reason for the course's status is visible.

### Phase 4 cohort-scoped sequence API (2026-11-12)

Added `POST /api/academic/sequence` as an API surface for a conditional sequence of explicitly supplied remaining course codes. It requires a program ID, entry cohort year, completed/current course-code lists, and student-supplied term credit limits. It checks that the selected cohort has an unambiguous modeled curriculum, that requested remaining courses belong to that curriculum, and that all course identities/credits come from the official catalog snapshot. The existing deterministic planner applies supported prerequisite/corequisite relations and source freshness checks. The response includes curriculum/course citations, blockers and assumptions, and states that this is not a degree audit, registration approval, or live-offering check. Responses are marked `no-store`; this route does not persist submitted course lists.

Course records without captured prerequisite wording are explicitly represented as `NO_LISTED_RULE`, not `VERIFIED_NONE`; they can appear in a conditional sequence only with an assumption that the snapshot's silence is not proof of eligibility or absence of other restrictions. Unsupported or malformed listed rules remain unscheduled. The API does not yet select electives/pathways, establish requirement completion, integrate into chat/UI, verify live sections, resolve timetable conflicts, or use student records. The full architecture remains 0 of 6 phases accepted; production is untouched.
